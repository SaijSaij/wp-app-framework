    #has_plugin()

    Twig function of the framework; its result is escaped like any value.

    {{ has_plugin(slug) }}

    Whether the plugin with this slug is active and has booted the framework, so its public template functions and filters are available. Calling them without the plugin is an error, so check first.

    {% if has_plugin('my-plugin') %}
    {{ my_plugin_note_count() }}
{% endif %}
    ParameterTypeDefaultDescription
    slugstringrequiredSlug of the plugin, e.g. my-plugin.

    Returns bool
