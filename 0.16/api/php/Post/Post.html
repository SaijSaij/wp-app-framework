    #Post

    Class. It extends AbstractPost.

    use Saij\WpAppFramework\Post\Post;

    A post of the post type post of WordPress. Meta classes and taxonomies of a theme or plugin name it in postTypes: [Post::class].

    #Constructor

    new Post()

    Creates a new post of the type; it is stored by save().

    #Methods

    #find()

    Post::find(int $id): ?static

    The post with the ID, in any status; null if it does not exist or has another post type.

    ParameterTypeDefaultDescription
    idintrequiredThe ID of the post.

    Returns ?AbstractPost

    #get()

    Post::get(int $id): static

    The post with the ID, in any status.

    ParameterTypeDefaultDescription
    idintrequiredThe ID of the post.

    Returns AbstractPost

    Throws InvalidArgumentException: If it does not exist or has another post type.

    #query()

    Post::query(): PostQuery

    A query for posts of the type: published posts, unsorted conditions, see PostQuery.

    Returns PostQuery<AbstractPost>

    #delete()

    delete(bool $force = false): void

    Moves the post to the trash, whatever its post type, or deletes it permanently with $force. A post already in the trash, and every post while the trash is disabled (EMPTY_TRASH_DAYS is 0), is deleted permanently.

    ParameterTypeDefaultDescription
    forceboolfalseDelete permanently instead of moving to the trash.

    Throws LogicException: If the post has not been saved.

    Throws RuntimeException: If WordPress cannot trash or delete the post, e.g. because it no longer exists or a filter (pre_trash_post, pre_delete_post) prevented it.

    ParameterTypeDefaultDescription

    getTitle(): string

    The title as stored, or as set by setTitle() before save().

    Returns string

    #getUrl()

    Returns ?string

    #meta()

    meta(string $class): object

    The meta object of a meta class (#[PostMeta] naming this post class), loaded on first use; the same object until the post object is gone. In templates the meta class is named by its #[PostMeta] name: post.meta('details').

    ParameterTypeDefaultDescription
    classclass-string<T>|stringrequiredThe meta class, or its #[PostMeta] name.

    Returns ($class is class-string<T> ? T : object)

    #save()

    save(): void

    Stores the post: checks the loaded meta objects against their schemas (nothing is written if a value is invalid), inserts or updates the post and writes the changed meta values and terms.

    Throws PostValidationException: If a meta value is invalid.

    Throws RuntimeException: If WordPress cannot save the post.
